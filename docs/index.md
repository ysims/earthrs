# AquaticRS

AquaticRS provides a consistent set of Earth observation abstractions focused on aquatic and
coastal remote sensing.

## Principles

- Clean APIs
- Readability and composability
- Extensibility
- Reproducibility
- Optional integrations and dependencies

## Scaffold modules

- `aquaticrs.scene.Scene`
- `aquaticrs.dataset.Dataset`
- `aquaticrs.indices`
- `aquaticrs.sensors`
- `aquaticrs.processing`
- `aquaticrs.sampling`
- `aquaticrs.ml`
